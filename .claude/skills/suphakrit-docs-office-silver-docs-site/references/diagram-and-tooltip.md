# ไดอะแกรม ซูม/ลาก tooltip และ ER วางผังเอง

อ้างอิงจาก `doc/site/template.html` (ฟังก์ชัน `enhance`, ส่วน tooltip) และ `doc/site/er_svg.py` ใช้เมื่อหน้าใหม่มีไดอะแกรมที่ใหญ่หรือพันกัน

## 1. กรอบดูไดอะแกรม (`enhance(div)`)

รับ element ที่มี `<svg>` (ผล Mermaid หรือ SVG ที่วาดเอง) แล้วห่อเป็นกรอบ `.dg`:

```
.dg                 ขอบ 1px โค้ง 4px พื้นขาว margin 1.4rem 0
├─ .dg-bar          แถบ --silver: [−] [NN%] [+] [พอดีกรอบ] [100%] [เต็มหน้าจอ]  …คำใบ้ชิดขวา
└─ .dg-view         overflow:hidden, สูง min(460px,70vh), cursor:grab, padding 8px, touch-action:none
```

พฤติกรรม (ตามโค้ด):
- อ่านขนาดจริงจาก `viewBox` ลบ `style`/`height` เดิมของ SVG แล้วกำหนด `width/height` ตามสเกล
- สเกลจำกัด **0.08–3**; ปุ่ม +/− คูณ/หาร **1.25**; Ctrl+ลูกกลิ้งคูณ **1.1 / 0.9**
- `พอดีกรอบ` = `min(1, กว้างกรอบ/กว้างภาพ, สูงกรอบ/สูงภาพ)` แล้วรีเซ็ต scroll; เริ่มต้นเรียกค่านี้
- แผนภาพ ER วางผังเอง (`.er-svg`): เริ่มที่ "พอดีความกว้าง" (สูงสุด 1.15×) และปรับความสูงกรอบตามภาพ
- ลาก: `pointerdown` เก็บตำแหน่ง → `pointermove` ปรับ `scrollLeft/Top` → `setPointerCapture`
- Shift+ลูกกลิ้ง = เลื่อนซ้าย-ขวา; ลูกกลิ้งปกติ **ไม่ถูกดักไว้** เพื่อให้หน้าเลื่อนต่อ
- เต็มหน้าจอ: `box.requestFullscreen()` และ CSS `.dg:fullscreen .dg-view{height:calc(100vh - 46px)}`

**บทเรียนจากต้นฉบับ:** เวอร์ชันแรกพอดีทั้งแผนภาพ ตัวอักษรเหลือ ~11% อ่านไม่ได้ จึงแก้เป็น (ก) แยกแผนภาพใหญ่เป็นกลุ่ม ๆ และ (ข) ให้ซูมได้ ถ้าแผนภาพมีเอนทิตีมากกว่า ~10 ให้แยกกลุ่มก่อนค่อยซูม

## 2. Tooltip ข้อมูลเต็ม (`data-tip`)

- ใส่ `data-tip="บรรทัดแรก = หัวข้อ\nบรรทัดถัด ๆ ไป = รายละเอียด"` (คั่นด้วย newline จริง) บนกลุ่ม SVG/element ใดก็ได้
- ใช้ **event delegation** ที่ `document` (`mousemove`) หา `e.target.closest('[data-tip]')` — ตัวที่ซ้อนในสุดชนะ (ฟิลด์ชนะการ์ด)
- สร้าง DOM ด้วย `textContent` (ไม่ใช้ innerHTML กับข้อความใน tip)
- ตำแหน่ง: เมาส์ +16/+18px, พลิกขึ้นบนถ้าล้นล่าง, ไม่ล้นขวา; `pointer-events:none`
- สไตล์: ดู `.tip` ใน `assets/office-silver.css`; เคอร์เซอร์ `help` บน `[data-tip]`
- เนื้อหา tip ของ ER: หัวการ์ด = ชื่อ + จำนวนฟิลด์ + ความสัมพันธ์ทั้งหมด (ฝั่งนี้:ฝั่งนั้น); ฟิลด์ = ชื่อ ชนิด คีย์ อ้างอิง หมายเหตุเต็ม; เส้น = คู่เอนทิตี + ชื่อความสัมพันธ์ + จำนวนสองฝั่ง
- **ข้อจำกัด:** tooltip ใช้เมาส์เท่านั้น ไม่มีทางเลือกสำหรับคีย์บอร์ด/สัมผัส (ต้นฉบับยังไม่แก้)

## 3. ER วางผังเอง (`er_svg.py`)

เหตุผล: Mermaid จัดผัง ER อัตโนมัติแล้วกล่องกระจายและเส้นยาวพันกันเมื่อมีเอนทิตีมาก จึงกำหนดตำแหน่งเอง

**หลักการ**
1. แบ่งเอนทิตีเป็นกลุ่มตามโดเมน (5 กลุ่ม) แต่ละกลุ่ม = ตารางช่อง `(col, row)`; เอนทิตีที่เจ้าของอยู่กลุ่มอื่นแสดงเป็น **การ์ดย่อเส้นประ** (ขอบ `#9ca3af`, หัว `#f3f4f6`)
2. การ์ด: กว้าง **268**, หัว **28**, แถวฟิลด์ **21**, ขอบ `#1f5fae` 1.4px, หัว `#e8f0fb`
3. ระยะ: ช่องไฟแนวนอน **44**, แนวตั้งขั้นต่ำ **52**, ขอบนอก **14**
4. **เส้นวิ่งเฉพาะ "ช่องทาง" ระหว่างแถว** (ไม่ทะลุการ์ด): ติดกันแนวนอน = เส้นตรง; อื่น ๆ = ลงจากการ์ดบน → วิ่งนอนในช่องทาง → ลงถึงการ์ดล่าง; ความสัมพันธ์ที่เดินไม่ได้โดยไม่ทะลุการ์ด **ไม่วาด** (ยังเห็นเป็น `→ เอนทิตี` ในแถว FK)
5. **เลน (lane):** เส้นนอนในช่องทางเดียวกันที่ช่วง x ซ้อนกันถูกแยกคนละระดับ (ห่าง 11px) ช่องทางขยายความสูงตามจำนวนเลน
6. เส้นที่ออกด้านเดียวกันของการ์ดเดียวกัน กระจายห่างกัน **22px**
7. **ป้ายชื่อความสัมพันธ์** วางเฉพาะที่ที่ไม่ชนการ์ด/เส้นอื่น/ป้ายอื่น (ทดสอบรูปทรงกล่องแล้วเลื่อนบน-ล่างหรือซ้าย-ขวา) ไม่พอที่ → ซ่อน (ดูใน tooltip)
8. ลำดับชั้นการวาด: การ์ด → เส้น → สัญลักษณ์ปลายเส้น → ป้าย → พื้นที่ชี้เมาส์ (เส้นโปร่งใสหนา 14px)

**สัญลักษณ์ปลายเส้น (ER จริง ไม่ใช่ตัวเลข):** ขีดคู่ = หนึ่งเดียว · วงกลม+ขีด = ศูนย์หรือหนึ่ง · ตีนกา+ขีด = หนึ่งหรือหลาย · ตีนกา+วงกลม = ศูนย์หรือหลาย; เส้นสี `#4b5563` หนา 1.7px

**ป้ายคีย์ในแถว:** ชิปเล็กหน้าชื่อฟิลด์ **มีเลขลำดับ** (`PK` เมื่อมีเดียว, `PK1 PK2…` เมื่อ composite, `FK1 FK2…`, `UK1…`) สี PK `#fef3c7/#92400e` · FK `#e0f2fe/#075985` · UK `#ede9fe/#5b21b6`; ฟิลด์ PK ตัวหนา; FK แสดง `→ ตารางปลายทาง` ชิดขวาสี `#075985`

**ข้อมูลเข้า:** อ่านจากไฟล์ Mermaid `erDiagram` เดิม (`er-diagram.mmd`) แล้วเพิ่มผังตำแหน่งเป็นข้อมูล (`ZONES`) ทำให้แก้ผังโดยไม่แตะโค้ดเส้น

**ฝังใน markdown:** SVG ต้องเป็น **บรรทัดเดียวไม่มีบรรทัดว่าง** ภายใน `<div class="er-svg">…</div>` ไม่เช่นนั้น `marked` จะตัดบล็อก HTML

## 4. Mermaid ที่ใช้ในเว็บ

ตั้งค่าที่ตรวจพบ: `theme:'base'`, ฟอนต์ Sarabun/Noto Sans Thai 15px, สีกล่อง `#e8f0fb` ขอบ `#1f5fae` เส้น `#4b5563`, `useMaxWidth:false` ทุกชนิด (ไม่บีบให้พอดีความกว้าง), `nodeSpacing/rankSpacing: 30`, กล่อง ER `entityPadding:10 minEntityWidth:90` และพื้น `.mermaid` ขาว ผลถูกห่อด้วย `enhance` เหมือนกัน
