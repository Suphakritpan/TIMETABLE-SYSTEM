--------------------------------------------------
HOW PAGES CONNECT (the main paths)
--------------------------------------------------
Install:            server admin runs `docker compose up` -> 0.0 first-run setup -> 3.1
Head, new term:     0.1 -> 2.1 -> 2.2 (Copy from last term) -> 2.4 steps (1) ... (9)
Head, new teacher:  2.3 invite -> email -> teacher 0.3 -> 4.1
Round:              head 2.4(3) opens round -> teachers get 1.1 notice -> 4.2 -> head sees status in 2.4(3)
Problem items:      head 2.4(4)  <->  teacher 4.3   (the SAME comment thread, seen from both sides)
Review:             head 2.4(8) sends draft -> teacher 4.4 -> 4.5 request -> head 2.4(8) approve/reject -> teacher 1.1
In-person change:   head 2.4(8) direct edit -> teacher 1.1 "changed by <head>: <note>" -> 4.4
After publish:      head 2.4.2 "start a change" -> new version -> affected teachers 1.1
Unknown PDF:        head 2.4(1) -> 2.4.1 -> institution admin 3.5 approves -> (optional) export to the open-source project

Step bar rule: a step unlocks when the one before is done. Going back to a done step and changing it marks the
later steps "out of date" - for THAT YEAR only when the change is inside one year tab.
