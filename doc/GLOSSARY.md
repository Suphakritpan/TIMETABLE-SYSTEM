# ระบบจัดตารางสอนอัตโนมัติ

ศัพท์กลางของระบบที่อ่านโครงสร้างหลักสูตรแล้วจัดตารางสอนให้ไม่ชน ใช้ร่วมกันระหว่างฝั่งหน้าเว็บ ฝั่ง backend และเอกสาร

## Language

### ตารางและเวลา

**คาบ**:
ช่วงเวลาหนึ่งช่องในตาราง ระบุด้วยวันและเลขคาบ เช่น จันทร์ คาบ 3
_Avoid_: ใช้ "คาบ" เรียกสิ่งที่ถูกวางลงในตาราง (ใช้ รายการสอน)

**รายการสอน**:
การสอนหนึ่งรายการที่ถูกวางในคาบหนึ่งของตาราง ผูกกับวิชา กลุ่มเรียน อาจารย์ และห้อง
_Avoid_: คาบ (เมื่อหมายถึงสิ่งที่ถูกวาง), class

**รายการสอนที่ยังไม่ลง**:
รายการสอนที่ระบบวางลงตารางไม่ได้ พร้อมเหตุผลและวิธีแก้ที่ใกล้ที่สุด แสดงอยู่ในถาด
_Avoid_: คาบค้าง

**ปักหมุด**:
การตรึงรายการสอนให้อยู่ที่เดิมเมื่อรันจัดตารางใหม่
_Avoid_: ล็อกรายการสอน

**ล็อก**:
สถานะที่แก้ไขหรือเข้าถึงไม่ได้ ใช้กับเวอร์ชันที่เผยแพร่แล้วและขั้นที่ยังไม่ปลดล็อกเท่านั้น
_Avoid_: ใช้ "ล็อก" เรียกการปักหมุด

### ปีการศึกษา

**ปีการศึกษา**:
ปีของภาคเรียนนับเป็น พ.ศ. เขียนเป็น ภาค/ปี เช่น 1/2570 ใช้ พ.ศ. ทั้งระบบ
_Avoid_: ปี ค.ศ. ในป้ายภาคเรียน เช่น 1/2027

### บทบาทและหน่วยงาน

**ภาควิชา**:
หน่วยของสถาบันที่มีหัวหน้า อาจารย์ ห้อง และโปรไฟล์ตารางของตนเอง ในอาชีวศึกษาหน้าจอแสดงว่า แผนกวิชา
_Avoid_: แผนกวิชา ในเอกสารกลาง (ใช้เฉพาะข้อความหน้าจอของอาชีวศึกษา)

**อาจารย์**:
ผู้สอนในภาควิชา บทบาทที่ส่งเวลาว่าง จัดอันดับวิชา และขอเปลี่ยนตาราง เห็นเฉพาะตารางของตน ในอาชีวศึกษาหน้าจอแสดงว่า ครู
_Avoid_: ครู ในเอกสารกลาง (ใช้เฉพาะข้อความหน้าจอของอาชีวศึกษา)

**ผู้ช่วย**:
บทบาทในภาควิชาที่ทำขั้น 1 ถึง 8 ได้เหมือนหัวหน้า แต่เผยแพร่ ลบหัวหน้า และเชิญผู้ช่วยคนอื่นไม่ได้
_Avoid_: ASSIST

**ผู้ดูแลสถาบัน**:
บทบาทระดับสถาบัน ไม่สังกัดภาควิชา ดูแลภาควิชา ห้องร่วม ปฏิทินการศึกษา รูปแบบหลักสูตร และระบบ
_Avoid_: ผู้ดูแลแพลตฟอร์ม (ไม่มีบทบาทนี้), บทบาทในภาควิชา

### ประเภทสถานศึกษา

**ประเภทสถานศึกษา**:
อาชีวศึกษา การศึกษาขั้นพื้นฐาน หรืออุดมศึกษา กำหนดรูปแบบหลักสูตรและคำเรียกบนหน้าจอ ตอนนี้ใช้งานได้เฉพาะอาชีวศึกษา
_Avoid_: ระดับการศึกษา
