## 0.2 ลืม / รีเซ็ตรหัสผ่าน (`/reset`, `/reset/:token`)

เทียบหน้า 0.1 ล็อกอิน ระบบเปิดใช้งานโดยไม่ต้องมี SMTP จึงไม่ใช้อีเมลเป็นทางเดียว

- **ขอรีเซ็ต:** ข้อความ "ติดต่อหัวหน้าภาควิชาหรือผู้ดูแลสถาบันเพื่อขอลิงก์ตั้งรหัสผ่านใหม่" และถ้าสถาบันตั้ง SMTP แล้ว มีช่องอีเมลกับปุ่ม "ส่งลิงก์รีเซ็ต" ข้อความตอบเหมือนกันเสมอ ไม่บอกว่าอีเมลนั้นมีบัญชีหรือไม่
- **ตั้งรหัสใหม่ (`/reset/:token`):** รหัสผ่านใหม่ 2 ช่อง (กรอกซ้ำ) ปุ่ม "ตั้งรหัสผ่าน" สำเร็จแล้วไปหน้า 0.1
- **ลิงก์หมดอายุ:** "ลิงก์นี้หมดอายุแล้ว ขอให้หัวหน้าหรือผู้ดูแลสร้างลิงก์ใหม่" ไม่แก้รหัสผ่าน
- **ฝั่งผู้ออกลิงก์:** ปุ่ม "สร้างลิงก์รีเซ็ตรหัสผ่าน" ที่ 3.2 (ผู้ดูแล → หัวหน้า) และ 2.3 (หัวหน้า → อาจารย์/ผู้ช่วย) แสดงลิงก์ให้คัดลอก แบบเดียวกับลิงก์เชิญ

## 1.2 บัญชีของฉัน (`/account`)

เทียบหน้าตั้งค่าบัญชีทั่วไป ใช้ได้ทุกบทบาท

- ข้อมูลส่วนตัว: ชื่อ อีเมล (ตั้งค่า) ภาษา ไทย / อังกฤษ
- เปลี่ยนรหัสผ่าน: รหัสเดิม รหัสใหม่ 2 ช่อง
- การสังกัด (อ่านอย่างเดียว): รายการภาควิชาและบทบาทในแต่ละภาควิชา และสถานะผู้ดูแลสถาบันถ้ามี
- ปุ่ม "ออกจากระบบ"
- บันทึกอัตโนมัติไม่ใช้ ใช้ปุ่ม "บันทึก" ต่อส่วน และแสดง "บันทึกแล้ว HH:mm" ตาม design system §6.1

## 2.4.1 ตั้งค่ารูปแบบไฟล์ (`/profiles/:id/setup/format`)

เทียบขั้น 1 และหน้าตรวจผล OCR (ซ้ายภาพหน้า PDF ขวาตาราง) แสดงเมื่ออัปโหลดมีสถานะ `needs_format`

- ซ้าย: ภาพหน้า PDF ที่ระบบอ่านไม่รู้จักเลย์เอาต์ พร้อมเลื่อนดูหน้าอื่น
- ขวา: รายการฟิลด์ที่ต้องจับคู่ (รหัสวิชา ชื่อวิชา ท-ป-น ภาคเรียน หมวดวิชา ประเภทวิชา กลุ่มอาชีพ) ผู้ใช้เลือกคอลัมน์บนภาพแล้วจับคู่กับฟิลด์
- ตัวอย่างผลที่อ่านได้จาก 3 หน้า ให้ตรวจก่อนบันทึก
- ปุ่ม "บันทึกเป็นรูปแบบใหม่" สถานะ `unverified` และข้อความ "รอผู้ดูแลสถาบันอนุมัติ" (3.5) ใช้ได้กับโปรไฟล์นี้ทันที
- ถ้าผู้ดูแลส่งกลับพร้อมหมายเหตุ แสดงหมายเหตุที่ขั้น 1
