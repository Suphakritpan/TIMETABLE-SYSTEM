# นักเรียนดูตารางที่เผยแพร่แล้วได้โดยไม่ล็อกอิน

โจทย์ต้องการให้นักเรียนตรวจตารางของตนเองบนเว็บได้ จึงเพิ่มหน้าสาธารณะแบบอ่านอย่างเดียว (แก้ D7 และ N3 ที่เดิมห้ามลิงก์สาธารณะ) แสดงมุมมองกลุ่มเรียนของเวอร์ชันที่หัวหน้าเผยแพร่แล้วของทุกภาควิชา พร้อมชื่ออาจารย์และห้อง ไม่แสดงร่าง ตารางระหว่างตรวจทาน อีเมล เวลาไม่ว่าง หรือความเห็น และยังไม่มีบัญชีหรือข้อมูลนักเรียนในระบบ (ข้อกำหนดข้อ 12 ใน data-model.md §4 คงเดิม) มุมมองอาจารย์และห้องยังต้องล็อกอิน

การเผยแพร่โดยหัวหน้าเป็นประตูเดียวที่ทำให้ตารางเปิดสาธารณะ ตารางที่จัดเสร็จหรือกำลังทดลองจัดยังเป็นร่างและไม่เคยเปิดสาธารณะ จึงไม่มีสวิตช์เปิด/ปิดรวมที่หน้าระบบ ถ้าภายหลังสถาบันต้องการปิดหน้านี้ทั้งหมด ค่อยเพิ่มตัวเลือกในหน้า 3.6

## Considered Options

- คงเดิม ไม่มีนักเรียนในระบบ แจก PDF ผ่านอาจารย์: ไม่ตรงโจทย์
- บทบาทนักเรียนล็อกอินด้วยรหัสนักศึกษา: ต้องมีข้อมูลนักเรียนและงานนำเข้ารายชื่อ ขัดข้อกำหนดข้อ 12 ใน data-model.md §4

## Consequences

ชื่ออาจารย์เปิดสาธารณะ ยอมรับได้เพราะสถานศึกษาประกาศตารางที่จัดเสร็จอยู่แล้ว ข้อมูลอื่นของอาจารย์ยังอยู่ภายใต้ N2 ฝั่ง backend ต้องมีเส้นอ่านอย่างเดียวที่ไม่ต้องล็อกอินและส่งเฉพาะฟิลด์ข้างต้น
