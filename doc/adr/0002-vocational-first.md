# อาชีวศึกษาเป็นประเภทสถานศึกษาแรก โครงหลักสูตรเป็นข้อมูล

เอกสารเดิมเขียนสำหรับมหาวิทยาลัย (มคอ.2, ค.บ./ศษ.ม./ปร.ด., ตัวอย่างหลักสูตร มจพ.) แต่ PDF ที่ผู้ใช้กลุ่มแรกอัปโหลดคือแผนการเรียนหลักสูตรอาชีวศึกษา (หมวดวิชาสมรรถนะแกนกลาง สมรรถนะวิชาชีพ วิชาเลือกเสรี กิจกรรมเสริมหลักสูตร) จึงให้อาชีวศึกษาเป็นประเภทสถานศึกษาแรกที่ใช้งานได้ ประเภทสถานศึกษาเป็นค่าของสถาบัน ตั้งที่หน้า 0.0 กำหนดรูปแบบหลักสูตรที่ใช้และคำเรียกบนหน้าจอ (ภาควิชาเป็นแผนกวิชา อาจารย์เป็นครู) ส่วนอุดมศึกษาและการศึกษาขั้นพื้นฐานยังไม่รองรับ หน้าเข้าสู่ระบบแสดงทั้งสามประเภทเป็นการ์ดบอกแผนงานโดยกดได้เฉพาะอาชีวศึกษา

## Considered Options

- ใช้โครงมหาวิทยาลัยเดิมกับไฟล์อาชีวะ: ขาดที่เก็บหมวดวิชา ประเภทวิชา กลุ่มอาชีพ ชั่วโมงกิจกรรม และข้อมูลวิชาบังคับก่อนสำหรับผังความต่อเนื่อง
- เขียนโครงข้อมูลใหม่ทั้งหมดสำหรับอาชีวะ: ทิ้งงานของอานนท์ และปิดทางไปประเภทอื่น

## Consequences

ER ต้องเพิ่มฟิลด์ตาม HANDOFF-ANON.md ข้อ 2.3–2.5 รูปแบบหลักสูตรต้องเป็นข้อมูล (D4) ไม่ฝังในโค้ด ข้อความหน้าจอต้องมาจากพจนานุกรมที่สลับตามประเภทสถานศึกษา
