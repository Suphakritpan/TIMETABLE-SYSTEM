## 0.2 ลืม / รีเซ็ตรหัสผ่าน (`/reset`, `/reset/:token`)

เทียบหน้า 0.1 ล็อกอิน: การ์ดกลางจอเดียว ไม่มี Nav ไม่มีแถบบน

**A. ขอรีเซ็ต (`/reset`)**

```
┌────────────────────────────────────┐
│ ระบบตารางเรียน                     │
│ ลืมรหัสผ่าน                         │
│                                    │
│ อีเมล  [____________________]      │
│ [ ส่งลิงก์รีเซ็ต ]  ← primary      │
│                                    │
│ ⓘ ถ้าอีเมลนี้มีในระบบและสถาบันตั้ง │
│   ค่าอีเมลไว้ เราจะส่งลิงก์ให้     │
│ ⓘ ถ้าไม่ได้รับอีเมล ให้ขอลิงก์     │
│   จากหัวหน้าภาควิชาหรือผู้ดูแล     │
│   ระบบสถาบัน                       │
│ ← กลับไปล็อกอิน                    │
└────────────────────────────────────┘
```
- กดแล้วแสดงข้อความเดิมเสมอ ไม่บอกว่ามีอีเมลนี้หรือไม่ (ไม่เปิดเผยว่าใครมีบัญชี)
- ถ้าสถาบันไม่ได้ตั้ง SMTP แสดงเฉพาะข้อความ "ขอลิงก์จากหัวหน้า/ผู้ดูแล" และซ่อนปุ่มส่ง

**B. ตั้งรหัสใหม่ (`/reset/:token`)**

```
│ ตั้งรหัสผ่านใหม่                   │
│ รหัสผ่านใหม่   [________]          │
│ ยืนยันรหัสผ่าน [________]          │
│ [ บันทึกรหัสผ่าน ]                 │
```
- ลิงก์หมดอายุ / ใช้แล้ว (410): InlineAlert error "ลิงก์นี้หมดอายุหรือถูกใช้แล้ว" + ปุ่ม "ขอลิงก์ใหม่"
- สำเร็จ: ไปหน้าล็อกอิน พร้อม Toast "เปลี่ยนรหัสผ่านแล้ว"

**C. ฝั่งผู้สร้างลิงก์ (ADMIN ที่ 3.2 / HEAD ที่ 2.3)** เทียบปุ่ม "เชิญ" ใน 2.3

```

                               └ ลบออกจากภาควิชา
Dialog ► ลิงก์รีเซ็ตรหัสผ่านของ นายสมชาย
        [ https://…/reset/ab12…   ] [คัดลอก]

        ⚠ ส่งลิงก์นี้ให้เจ้าของบัญชีเท่านั้น
```

- เมนูนี้ซ่อนสำหรับผู้ใช้ที่เป็น ADMIN หรือเป็น HEAD ภาควิชาอื่น (หัวหน้าสร้างให้ไม่ได้ ต้องเป็น ADMIN, ดู [api §2](api.md))

## 1.2 บัญชีของฉัน (`/account`)

เทียบหน้า "ตั้งค่าบัญชี" ทั่วไป: ฟอร์มกว้างสูงสุด 640px แบ่งเป็นส่วนด้วยหัวข้อ + เส้น 1px ไม่ซ้อนการ์ด

```
บัญชีของฉัน
──────────────────────────────
ข้อมูลส่วนตัว
  ชื่อ        [______________]
  อีเมล       [______________]   (เปลี่ยนแล้วต้องยืนยันด้วยรหัสผ่าน)
  ภาษา        (•) ไทย  ( ) English
  [ บันทึก ]
──────────────────────────────
เปลี่ยนรหัสผ่าน
  รหัสผ่านปัจจุบัน [________]
  รหัสผ่านใหม่     [________]
  ยืนยัน           [________]
  [ เปลี่ยนรหัสผ่าน ]
──────────────────────────────
สังกัดของฉัน   (อ่านอย่างเดียว)
  ภาควิชาคอมพิวเตอร์ศึกษา   หัวหน้า
  ภาควิชาอื่น              อาจารย์
  ผู้ดูแลสถาบัน            ✓       (แสดงเมื่อ is_admin)
──────────────────────────────
[ ออกจากระบบ ]  ← tertiary
```
- "สังกัดของฉัน" ให้ผู้ใช้เห็นว่าตัวสลับภาควิชามาจากไหน แก้ไม่ได้ (หัวหน้า/ผู้ดูแลเป็นคนจัดการ)
- ช่วงการเปลี่ยนภาษา: มีผลทันที ไม่ต้องโหลดหน้าใหม่
- ชั่วโมงสอนสูงสุดต่อวัน **ไม่อยู่ที่นี่** อยู่ที่ 4.2 เวลาว่างของฉัน เพราะเป็นค่าต่อภาคเรียน (D12)

## 2.4.1 ตั้งค่ารูปแบบ (`…/setup/format`)

เทียบขั้น 1 ตั้งค่า: Stepper อยู่บนสุด ขั้น 1 เป็นขั้นปัจจุบัน เข้ามาเมื่อระบบไม่รู้จักเลย์เอาต์ PDF เท่านั้น

```
Stepper ① ตั้งค่า (ปัจจุบัน) ② ตรวจข้อมูล 🔒 …
ไม่รู้จักรูปแบบหลักสูตรนี้  ← InlineAlert warning
ช่วยบอกระบบว่าแต่ละคอลัมน์คืออะไร (ทำครั้งเดียวต่อรูปแบบ)
┌ SplitPane ───────────────┬──────────────────────────┐
│ หน้าตัวอย่าง PDF (หน้า 3)│ ชื่อรูปแบบ [__________]  │
│ ┌──────────────────────┐ │ คอลัมน์ที่ชี้แล้ว        │
│ │ ตารางในไฟล์          │ │  1 รหัสวิชา      ✓ ชี้แล้ว│
│ │ ▒ ▒ ▒ ▒ ▒            │ │  2 ชื่อวิชา      ✓        │
│ └──────────────────────┘ │  3 หน่วยกิต      ✓        │
│ [คลิกคอลัมน์ในตัวอย่าง]  │  4 ทฤษฎี-ปฏิบัติ  ⚠ ยังไม่ชี้ │
│                          │ รูปแบบหน่วยกิต  [ ท-ป-น ▾]│
└──────────────────────────┴──────────────────────────┘
[ กลับ ]                      [ ลองอ่านด้วยรูปแบบนี้ ] ← primary (disabled จนครบ)
```
- คลิกคอลัมน์ในภาพตัวอย่าง แล้วเลือกว่าคือฟิลด์ไหน ฝั่งขวาแสดงสถานะ ✓ / ⚠ ต่อฟิลด์ที่ต้องมี
- "ลองอ่านด้วยรูปแบบนี้" แสดงแถวตัวอย่าง 5 แถวใน Dialog ให้ตรวจก่อนบันทึก
- บันทึกแล้วสถานะรูปแบบ = `unverified` (ใช้ได้กับงานนี้ทันที) Toast: "บันทึกรูปแบบแล้ว รอผู้ดูแลระบบสถาบันอนุมัติ" ผู้ดูแลอนุมัติ/ปฏิเสธที่ 3.5 ถ้าปฏิเสธ หัวหน้าเห็นหมายเหตุที่ขั้น 1
