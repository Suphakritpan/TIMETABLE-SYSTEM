## วิธีอ่าน

| สัญลักษณ์ | ความหมาย |

## F4 อัปโหลดและอ่านไฟล์หลักสูตร

**ผู้ทำ** HEAD / ASSISTANT · **เส้นทาง** A3-A4

**[2.4 ขั้น 1]** (อัปโหลด) → ระบบเก็บ `og_upload` (ไฟล์ตามที่ให้มา **ไม่เคยแก้**)

**ไฟล์ชนิดไหน** (ดูจากเนื้อหา ไม่ใช่ชื่อ):

| ชนิด | ทำ |
|---|---|
| PDF ที่มีข้อความ / Word / Excel | แปลง → normalise → `normalised_upload` |
| สแกน / รูปถ่าย / หน้า PDF ที่ไม่มีข้อความ | OCR + glyph tool → `normalised_upload` |
| **!!** ไม่ใช่เอกสาร (ว่าง เสีย zip PDF ที่ล็อก) | "อ่านไฟล์นี้ไม่ได้: <เหตุผล>" · ไม่บันทึกอะไร |

**เลย์เอาต์เป็นรูปแบบที่รู้จักไหม:**

- **ใช่** → การ์ด "สิ่งที่เราพบ": รูปแบบ · เวอร์ชันหลักสูตร · ชั้นปี · ภาคเรียน · รูปแบบหน่วยกิต แต่ละค่ามีหน้าที่มา → (ยืนยัน) หรือ (ไม่ถูก → เลือกรูปแบบอื่น)
- **ไม่** → **[2.4.1 ตั้งค่ารูปแบบ]** (ชี้ว่าคอลัมน์ไหนคือรหัส / ชื่อ / หน่วยกิต บนหน้าตัวอย่าง) → บันทึกเป็น format definition **"unverified"** → ADMIN เห็นใน 3.5 → **F11**

**[2.4 ขั้น 2 ตรวจข้อมูล]** ต่อแท็บ หลักสูตร × ชั้นปี: ตาราง \| ผังกระบวนวิชา

- ค่าที่ตัวอ่าน **มั่นใจ**: ปกติ
- ค่าที่ **ไม่มั่นใจ**: **สีแดง** พร้อมเหตุผล + ภาพครอบตัดของหน้า
- (แถวแดงถัดไป) → PDF เปิดข้างตาราง ไฮไลต์ตำแหน่ง → (แก้ค่า) หรือ (ถูกแล้ว)
- ยังมีแดงเหลือ? → **ใช่:** "ไปต่อ" ยังล็อก ("เหลือ 3 ค่าที่ต้องการคุณ") · **ไม่:** ขั้น 2 เสร็จ

**==>** ทุกแถวของแผนมี: หลักสูตร · ชั้นปี · ภาคเรียน · รหัส (หรือ "slot") · ชื่อ · หน่วยกิต L-P-S

**!!** วิชาเดียวกันอ่านได้ต่างกันระหว่าง "แผน" กับ "รายการวิชา" → แดง แสดงสองค่า หัวหน้าเลือก
**!!** อัปโหลดไฟล์ใหม่แทนที่ไฟล์เดิม → ขั้นหลังจากนั้น "ล้าสมัย" **เฉพาะหลักสูตรนั้น**

## F7 กฎ ตรวจ สร้าง จัดตาราง

**ผู้ทำ** HEAD/ASSISTANT · **เส้นทาง** A7-A8

### ขั้น 5: กฎ

- ตารางเวลา (จากโปรไฟล์) · กลุ่มต่อ หลักสูตร × ชั้นปี · จำนวนห้อง · วิชาเลือก
- วิชาเลือกแต่ละช่อง → **(Schedule: เลือกวิชา)** หรือ **(Reserve: เก็บชั่วโมงไว้ว่าง)**
- กฎ soft: เปิด/ปิด + น้ำหนัก · กฎ hard (จากหลักสูตร) แสดงแต่แก้ไม่ได้
- **(Check)** → รายงาน pre-check: OK / ปัญหา / กฎเสี่ยง

| เป็นไปไม่ได้เมื่อนับดู? | ทำ |
|---|---|
| ใช่ | เหตุผล + วิธีแก้ใกล้สุด ("ปี 2 ต้องการ 38 ชม. สัปดาห์มี 30") → กลับไปกฎ |
| ไม่ | **(Acknowledge)** → Generate ปลดล็อก |

### ขั้น 6: สร้างและจัดตาราง

1. **(Generate)** → ได้ตัวเลือกที่ดีที่สุด + คะแนนคุณภาพ
2. ลงครบทุกคาบ? → **ใช่:** ตารางเรียน · **ไม่:** **ตารางบางส่วน + ถาด** (แต่ละคาบมีเหตุผล + วิธีแก้ใกล้สุด)
3. (ลากคาบ) → ตรวจสดตอนวาง: OK หรือช่องแดง + เหตุผล
4. (ปักหมุดคาบที่ตกลง) · (รันใหม่รอบหมุด: เฉพาะ หลักสูตร × ชั้นปีนี้ที่ขยับ)
5. อาจารย์ที่ไม่ว่างใน **ภาควิชาอื่น** แสดงเป็นช่องเทา "ไม่ว่างที่อื่น"

**!!** FET ค้างหรือแครช → "ตัวจัดตารางหยุด: <เหตุผล>" · **เก็บผลดีล่าสุดไว้**

**ผู้ทำ** HEAD เท่านั้น · **เส้นทาง** A11-A12, B5

1. **[2.4 ขั้น 9]** (เผยแพร่)
   - **ASSISTANT?** → "มีแต่หัวหน้าที่เผยแพร่ได้" + (ขอให้หัวหน้า) → หัวหน้าได้แจ้งเตือน
2. → **เวอร์ชัน 1 ล็อก** · แจ้งอาจารย์ทุกคน · (ดาวน์โหลด / พิมพ์) ต่อกลุ่ม อาจารย์ ห้อง

**ภายหลัง:**

1. **[2.4.2 เวอร์ชัน]** (เริ่มการเปลี่ยนแปลง) → ร่างเวอร์ชันใหม่ (เวอร์ชันที่เผยแพร่ยังใช้ได้)
2. (เปลี่ยน) → ตรวจผลกระทบ + เปลี่ยนน้อยที่สุด → (เผยแพร่) → **เวอร์ชัน 2** แจ้งเฉพาะอาจารย์ที่ได้รับผลกระทบ
