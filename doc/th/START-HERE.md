# ระบบตารางเรียน: เอกสารการออกแบบ ขั้นตอนที่ 1-5

ระบบจัดตารางเรียนอัตโนมัติสำหรับมหาวิทยาลัยไทย อ่านหลักสูตรจากไฟล์ PDF (มคอ.2) ให้หัวหน้าภาควิชากับอาจารย์วางแผนภาคเรียนร่วมกัน แล้วสร้างตารางเรียนที่ไม่ชนกันให้พิมพ์ได้

## วิธีดู (ไม่ต้องติดตั้งอะไร)

- **รูปภาพ:** ดับเบิลคลิกไฟล์ `.png`
- **ต้นแบบ:** ดับเบิลคลิก `prototype.html` เปิดในเบราว์เซอร์
- **ไฟล์ข้อความ:** เปิดด้วยโปรแกรมแก้ไขข้อความใดก็ได้
- **เว็บเอกสารนี้:** เปิด `doc/site/index.html`

## ควรรู้

> - **wireframe เป็นสีเทาโดยตั้งใจ** แสดงโครงหน้าและการไหลของงาน ไม่ใช่หน้าตาจริง
> - **ข้อมูลตัวอย่างเป็นหลักสูตรจริง** (ครุศาสตร์อุตสาหกรรม สาขาคอมพิวเตอร์ศึกษา มจพ.) ส่วนชื่อบุคคลเป็นชื่อสมมติ
> - บางไฟล์อ้างถึง `tech-stack-list.txt` ซึ่งเป็นสเปกเทคนิคฉบับเต็ม **ไม่ได้รวมมาในชุดนี้**
> - ไฟล์ `.py` ใช้วาดรูปใหม่เท่านั้น ไม่จำเป็นต้องใช้

## สิ่งที่ช่วยได้มากที่สุด

ลองใช้ต้นแบบในบทบาท **หัวหน้าภาควิชา** และ **อาจารย์** แล้วจดสิ่งที่สับสน:

1. ขั้นตอนที่หาไม่เจอ
2. คำที่ไม่เข้าใจ
3. สิ่งที่คาดว่าจะทำงานต่างออกไป
